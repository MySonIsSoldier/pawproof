# PawProof 아티클 편집 계획과 주제 백로그

기준일: 2026-10-03
상태: 사용자 요청에 따른 편집 기획안. 키워드 검색량 조사와 개별 글 작성은 아직 완료하지 않았다.

## 이 문서의 역할

이 문서는 PawProof 아티클의 브랜드 기준, 우선 주제, 키워드 후보와 글별 진행 상태를 관리한다. 특정 발행 날짜를 정하지 않고 먼저 쓸 순서를 정한다.

- 저장·권한·Markdown·발행 절차는 [아티클 제품·운영 기준](ARTICLE_CURATION.md)이 정본이다.
- 실제 글 작성에는 [아티클 작성 system prompt](ARTICLE_WRITING_SYSTEM_PROMPT.md)를 사용한다.
- 제품 범위는 [제품 기획](PRODUCT_PLAN.md), 규정과 일정에 관한 사실 표현은 [판정·일정 복구 기준](RULES_AND_RECOVERY.md)을 따른다.
- 외부 검색량이나 키워드 경쟁도를 확인하지 않은 후보는 **키워드 가설**로 표시한다. 검색량을 추정하거나 확인한 것처럼 쓰지 않는다.

## 브랜드와 편집 목적

### 편집 약속

**반려견과 가고 싶은 곳을 포기하기 전에, 내 강아지의 조건과 방문 시간에 무엇을 확인해야 하는지 알려주고 가능한 경우 코스를 이어갈 방법을 찾는다.**

PawProof의 글은 일반적인 반려견 상식 모음이 아니다. 보호자가 장소별 조건을 이해하고, 모르는 점을 문의하고, 문제가 생기면 여행의 목적을 최대한 유지할 수 있도록 돕는다. 가능한 곳과 아직 확인이 필요한 곳을 명확히 나눈다.

### 우선 독자

- 반려견과 자가용으로 당일 여행을 계획하고 여러 장소를 방문하려는 보호자.
- 체중·견종·마릿수·실내외 구역·방문 시간 때문에 안내를 다시 확인해야 하는 보호자.
- 특히 중대형견 및 다견 가구의 질문을 놓치지 않되, 소형견 보호자도 같은 글을 활용할 수 있게 쓴다.
- 처음 여행하는 보호자에게는 낯선 용어를 풀어서 설명하고, 숙련된 보호자에게는 조건과 근거를 빠르게 찾을 수 있게 구성한다.

### 콘텐츠 비중 제안

| 축 | 비중 제안 | 다루는 질문 |
|---|---:|---|
| 출발 전 장소·조건 확인 | 50% | “동반 가능 표시가 내 강아지와 이 구역에도 적용될까?” |
| 코스 설계와 일정 복구 | 30% | “한 곳을 못 가면 이동과 이후 일정은 어떻게 바꿀까?” |
| 여행에 연결되는 산책·행동·지역 안내 | 20% | “강아지의 페이스와 실제 확인된 지역 정보를 일정에 어떻게 반영할까?” |

비중은 편집을 위한 시작 가설이며 방문·검색 성과를 측정한 결과가 아니다. 넓은 먹이·품종·건강 상식으로 빠르게 확장하기보다, 여행 준비와 연결되는 주제를 먼저 다룬다.

## 주제 선정 원칙

1. 글 하나는 독자가 실제로 던지는 질문 하나에 답한다. 검색 의도가 다른 질문을 키워드만 비슷하다는 이유로 한 글에 합치지 않는다.
2. 핵심 글은 `내 강아지 조건 확인 → 방문지 확인 → 코스 검사·복구` 중 한 단계 이상을 돕는다.
3. 제목과 본문에 검색어를 자연스럽게 쓰되 같은 키워드를 반복해 채우지 않는다.
4. 키워드의 검색량·경쟁도는 검색 결과, Search Console 또는 적절한 키워드 도구에서 확인하기 전까지 미확인으로 둔다.
5. 지역별·장소별 글은 실제로 일치하는 장소와 출처가 확보된 경우에만 만든다. 지역명만 바꾼 대량 페이지는 만들지 않는다.
6. 법·장소 규정·운영시간처럼 바뀔 수 있는 정보는 글 작성 시점에 다시 확인한다. 발행 날짜와 규정 확인 날짜를 같은 것으로 표현하지 않는다.
7. 의료·영양·행동 교정 주제는 공신력 있는 수의·전문 자료를 확인하고, 진단이나 개별 치료 조언을 하지 않는다. 좋은 출처를 찾지 못하면 주제를 보류하거나 일반적인 문의·준비 방법으로 범위를 좁힌다.

## 글별 진행 상태 정의

글 카드의 체크박스는 실제 작업이 끝났을 때만 갱신한다.

- **키워드 검증:** 해당 검색어와 독자 의도를 실제 검색 결과나 사용 가능한 분석 자료로 확인했다. 확인할 수 없으면 미체크로 둔다.
- **출처 조사:** 중요한 사실을 뒷받침하는 출처를 읽고 확인일과 적용 범위를 기록했다.
- **개요·초안:** 본문 초안이 실제로 작성되었다. 답변 안에만 작성한 경우 CMS 저장으로 표시하지 않는다.
- **사실·브랜드 검수:** 출처와 문장을 대조하고 PawProof의 불확실성·제품 범위를 검토했다.
- **CMS 초안:** 편집기 또는 허가된 서버 API에 초안이 저장되고 slug/ID를 확인했다.
- **발행:** 공개 상세 페이지에서 발행 상태와 실제 내용을 확인했다.

체크 상태와 별도로 `CMS slug/ID`를 기록한다. 초안을 작성했다고 발행으로 표시하지 않고, 자동화도 발행 상태를 만들거나 바꾸지 않는다.

## 키워드 검증과 글 작성 전 확인

- 실제 검색 결과에서 사용자가 쓰는 표현과 질문 형태를 확인한다.
- Search Console 자료가 있으면 실제 노출 검색어와 글 진입·코스 검사 흐름을 함께 본다.
- 검색량 도구가 없으면 수치를 만들지 말고 `검색량 미확인`으로 둔다.
- 주 키워드 하나와 보조 키워드를 정하되, 같은 검색 의도의 동의어만 본문에서 자연스럽게 사용한다.
- 한 글에서 해결하기 어려운 별도 의도는 별도 후보로 남긴다. 콘텐츠 수를 늘리기 위해 불필요하게 분리하지 않는다.
- 기존 공개 글 확인이 불가능하면 중복 여부를 미확인으로 표시한다.

2. Search Console에서 실제 질문이 들어오거나, 편집·사용자 문의에서 반복되는가?

5. 법·운영 정보가 바뀌었거나 사용자 피드백으로 재검토가 필요한 글은 없는가?
