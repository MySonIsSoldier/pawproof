# 인천 장소 앱 조사 안내 — 사용자 실행용

작성일: 2026-09-12 · 상태: **조사 요청서. 앱 조사 결과나 업체 확인 완료 기록이 아니다.**

## 1. 지금 할 일

**반려생활과 네이버지도에서 아래 4곳을 검색하고, 반려견 이용 안내·운영시간 화면과 공유 링크를 전달한다.** 직접 방문·전화·예약·결제는 이번 작업에 필요하지 않다. 앱에 없는 장소나 적혀 있지 않은 조건을 끝까지 찾을 필요도 없다.

1. 누닝 펫푸드카페
2. 개떼놀이터 인천점
3. 문차이나
4. 뻘다방

우선 **누닝 1곳의 자료만 먼저 전달**해도 된다. Codex가 정보의 유용성과 캡처 범위를 확인한 뒤 나머지를 같은 방식으로 진행한다. 첫 4곳은 데이터 부족·충돌을 확인할 표본이며, 서로 가까운 완성 여행 코스라는 뜻은 아니다.

권장 시간 예산은 가게당 5~10분, 총 20~40분이다. 실제 소요시간을 측정한 값은 아니다. 한 앱에서 두 가지 검색어를 사용해도 찾지 못하면 다음 앱으로 이동한다. 10분이 지나면 찾은 내용만 보내고 종료해도 조사 완료로 기록한다.

## 2. 역할과 완료 기준

| 사용자 | Codex |
|---|---|
| 앱에서 장소와 주소 확인 | 기존 KTO ID·시 자료·주소와 동일 장소인지 검수 |
| 동반 안내·공지·운영시간 화면 확보 | 체중·마릿수·구역·준비물·시간·예외 조건 추출 |
| 공유 링크와 열람 날짜 전달 | 공개 웹·운영기관·업체 원출처를 추가 조사 |
| 정보가 없거나 접근이 안 된 경우 기록 | 미확정·출처 충돌·동일 원천의 재게시를 구분 |
| 선택적으로 휴대폰에서 PawProof 사용성 확인 | 반영 가능한 근거 선별, 필요한 구현과 테스트 수행 |

**사용자 조사 완료와 규정 확정은 다르다.** 검색했지만 정보가 없다는 기록도 정상적인 조사 결과다. 사용자가 모든 항목을 채워야 개발이 진행되는 구조로 만들지 않는다. 실제 현장 이용 검증은 별도의 미완료 항목으로 유지한다.

## 3. 사용할 앱과 확인 순서

앱 버전·로그인 상태에 따라 메뉴 이름과 위치가 다를 수 있다. 아래는 찾아야 할 정보의 종류와 탐색 순서이며, 현재 앱 화면을 직접 조작해 검증한 메뉴 경로는 아니다.

| 순서 | 앱/웹 | 찾을 정보 | 넘어가는 기준 |
|---|---|---|---|
| 1 | **반려생활** — 앱스토어에서 서비스명 검색, [공식 홈페이지](https://www.ban-life.com/)로 서비스 확인 | 장소 상세의 동반 안내, 크기·체중, 이용 공간, 필수 준비물, 추가 비용, 정보 기준일 | 장소 검색 기능을 찾기 어렵거나 숙소만 나오면 지도 앱으로 이동 |
| 2 | **네이버지도** — [웹 진입점](https://map.naver.com/) | 정확한 주소·지점, 업체 소개/정보, 업체가 올린 소식·공지·이용 안내 사진, 영업시간 펼침 | 동반 안내가 없으면 `동반 안내 미발견` 기록 |
| 3, 선택 | **카카오맵** — [웹 진입점](https://map.kakao.com/) | 앞선 앱에 없는 주소·시간·홈페이지 연결이나 서로 다른 정보 | 첫 두 앱에서 충분히 찾았으면 생략 |
| 4, 선택 | 지도 상세에 연결된 업체 홈페이지·공식 SNS | 날짜가 있는 이용 규정·변경 공지 | 연결된 공식 계정인지 확인하기 어렵거나 접근이 막히면 링크만 전달 |

반려생활 공개 홈페이지는 확인했지만, **아래 4개 업소의 반려생활 앱 등록 여부는 아직 확인하지 못했다.** 검색 결과가 없다는 이유로 폐업·동반 불가로 판단하지 않는다. 네이버지도·카카오맵은 이번 웹 도구에서 페이지 본문을 읽지 못했으므로 개별 등록 여부와 메뉴를 확인했다고 주장하지 않는다.

네이버지도에서 볼 순서는 **주소 → 업체 소개/정보 → 업체 소식·공지 → 영업시간 → 이용 안내 사진**이다. 리뷰는 이 자료들에 규정이 없거나 충돌할 때만 선택적으로 본다. 방문객 후기와 업체 게시물을 같은 종류의 근거로 기록하지 않는다.

주변 검색을 위해 현재 위치를 사용할 필요는 없다. 장소명과 아래 도로명 주소로 검색한다. 별도 유료 앱 설치나 예약 결제는 요청하지 않는다.

## 4. 1차 필수 대상 4곳

아래 주소와 비교 기준은 **기존에 검수한 인천시 2026-01-19 자료**에서 가져왔다. 현재 영업·주소·규정이 그대로라는 보장은 없으며, 앱에서 보이는 내용을 기존 값에 맞춰 적으면 안 된다. 행정구역 이름이 달라도 도로명·건물번호를 함께 캡처하고, 이전·다른 지점 여부는 Codex가 검토한다.

### A01. 누닝 펫푸드카페 — 가장 먼저

- 식별 주소: **인천 청라커낼로 270**. 기존 시 자료에는 서구로 기재.
- 내부 연결 번호: KTO `2603720` — 사용자가 입력할 필요 없음.
- 검색어: `누닝 펫푸드카페` → `누닝 청라`. 반려생활에서 안 나오면 네이버지도에서 같은 검색어 사용.
- 조사 이유: 기존 자료의 체중·운영시간·휴무 조건을 현재 게시 안내와 비교하고, 마릿수 조건을 찾기 위함.
- 기존 시 자료의 비교 기준: 체중 20kg 이하, 실내 전체, 12:00~20:00, 월·화 휴무. **현행 확정값 아님.**

찾을 내용:

1. 체중 기준이 적혀 있는가? `이하/미만`, 대형견 예외까지 포함해 캡처한다.
2. 실내 전체 이용인지, 안고 있어야 하는지, 이동장이 필요한지 확인한다.
3. 한 일행 또는 보호자 1인당 반려견 수 제한 문구가 있는가?
4. 매너벨트·배변패드 등이 **제공/판매**되는 것인지 **필수 착용**인지 구분되는 안내가 있는가?
5. 현재 표시된 영업시간·정기 휴무·임시 휴무는 무엇인가?

전달할 화면: 주소, 반려견 안내, 영업시간. 체중이나 준비물 예외가 별도 공지에 있으면 그 공지만 추가한다.

### A02. 개떼놀이터 인천점

- 식별 주소: **인천 다남로 278**. 기존 시 자료에는 계양구로 기재.
- 내부 연결 번호: KTO `2848931`.
- 검색어: `개떼놀이터 인천점` → `개떼놀이터 다남로`. **다른 지역 지점과 구분한다.**
- 조사 이유: 체중·브레이크 타임·휴무가 출처별로 달라 이용 범위와 함께 확인해야 한다.
- 기존 시 자료의 비교 기준: 20kg 이하, 전체 공간, 11:00~22:00, 평일 16:00~17:00 휴게, 수요일 휴무. **현행 확정값 아님.**

찾을 내용:

1. 소형견·중형견·대형견의 정확한 허용 기준이 있는가? kg 또는 체고 기준이 있다면 단위를 그대로 남긴다.
2. 실내 식사 공간·운동장·수영장의 규정이 각각 다른가? 수영장 허용을 실내 식사 허용으로 바꾸지 않는다.
3. 반려견 수·견종·연령·등록/접종·매너벨트 등 입장 조건이 있는가?
4. 평일·주말 영업시간, 브레이크 타임, 마지막 주문/입장, 정기 휴무가 어떻게 표시되는가? 자정 이후 마감이면 화면 그대로 전달한다.
5. 반려견 입장료와 보호자 주문 조건이 있는가? 식사 주문과 음료 주문의 조건이 다른가?

전달할 화면: 지점과 주소, 이용 수칙, 시간 펼침 화면, 구역별 별도 안내가 있으면 추가. 수영장은 부가 정보이며 찾지 못해도 된다.

### A03. 문차이나

- 식별 주소: **인천 차이나타운로 20**. 기존 시 자료에는 중구로 기재.
- 내부 연결 번호: KTO `2445137`.
- 검색어: `문차이나 인천` → `문차이나 차이나타운`.
- 조사 이유: 실제 식사를 해결할 수 있는지, 체중·테라스 조건이 현재도 적용되는지 확인해야 한다.
- 기존 시 자료의 비교 기준: 20kg 이하, 테라스 좌석만, 10:30~21:00, 월요일 휴무. **현행 확정값 아님.**

찾을 내용:

1. 테라스만 가능한가, 실내 지정 좌석도 가능한가? 층·룸·좌석별 구분이 있는가?
2. 체중·견종 제한 또는 명시적인 제한 없음 문구가 있는가?
3. 이동장·유모차 사용 시 실내 이용 예외가 있는가? 이동장에 넣어도 실내 불가인지 구분한다.
4. 여러 마리 동반, 좌석 사전 예약, 추가 비용, 보호자 주문 조건이 있는가?
5. 테라스의 우천·계절 운영 안내, 영업시간·휴무·마지막 주문 안내가 있는가?

전달할 화면: 주소, 반려견 좌석·체중 안내, 시간, 예약/우천 공지가 있으면 추가.

참고: [비마이펫의 문차이나 페이지](https://bemypet.kr/pet-places/2924)는 검색 결과에 관광공사 데이터를 출처로 표시한다. Codex가 원천 중복을 확인할 참고 링크이며, 사용자에게 추가 앱 설치를 요구하는 대상은 아니다. 해당 페이지의 정보만으로 새로운 업체 확인을 얻었다고 보지 않는다.

### A04. 뻘다방

- 식별 주소: **인천 영흥면 선재로 55**. 기존 시 자료에는 옹진군으로 기재.
- 내부 연결 번호: KTO `2834224`.
- 검색어: `뻘다방` → `뻘다방 선재도`.
- 조사 이유: 체중 제한의 근거와 실제 이용 공간, 시간·휴무를 보강해야 한다.
- 기존 시 자료의 비교 기준: 30kg 이하, 10:00~20:30, 14:30~15:00 휴게, 화요일 휴무. 동반 공간은 빈칸. **현행 확정값 아님.**

찾을 내용:

1. 실내·테라스·야외 중 어디를 이용할 수 있는가? 주문하러 들어가는 것과 실내 착석이 구분되는가?
2. 30kg 등 체중 수치가 명시되는가? 견종·마릿수 조건은 있는가?
3. 목줄·이동장·유모차 등 필수 준비물이나 허용 예외가 있는가?
4. 현재 영업시간·휴무·브레이크 타임·마지막 주문이 어떻게 표시되는가?
5. 야외 공간의 우천·계절 운영, 반려견 추가 요금·주문 조건이 있는가?

전달할 화면: 주소, 실내외 안내, 체중 안내, 시간. 홈페이지·공식 SNS 연결이 보이면 링크를 함께 전달한다.

## 5. 모든 장소에서 빠뜨리지 않을 정보

아래 표를 직접 채우는 것은 선택이다. **화면만 보내도 Codex가 표로 정리한다.** 정보가 없는 항목을 추측해서 채우지 않는다.

| 항목 | 찾아야 할 표현 | 주의점 |
|---|---|---|
| 장소 식별 | 상호·지점·도로명·건물번호·층 | 이름이 같아도 다른 지점일 수 있음 |
| 이용 구역 | 실내, 테라스, 야외, 지정석, 놀이터 | 사진에 개가 있다는 이유만으로 해당 공간 허용을 확정하지 않음 |
| 체중·체고 | 수치·단위·이하/미만·구역별 기준 | `소형견`을 임의로 `10kg 이하`로 변환하지 않음 |
| 견종·기타 제한 | 특정 견종, 연령, 발정기, 공격성 관련 안내 | 예외와 적용 대상을 포함한 문장 필요 |
| 마릿수 | 보호자 1인당, 일행당, 테이블당 | 두 마리 방문 후기는 무제한 허용의 증거가 아님 |
| 준비물·증빙 | 목줄, 이동장, 입마개, 매너벨트, 등록·접종 | 필수/권장/제공/판매를 구분 |
| 시간 | 요일별 운영, 휴게, 마지막 입장·주문, 계절 | 오늘의 `영업 중` 표시만으로 여행 날짜 영업을 확정하지 않음 |
| 요금·예약 | 반려견 요금, 최소 주문, 지정석 예약 | 특정 상품·좌석에만 적용되는 조건 보존 |
| 시점 | 게시·수정일, 적용 시작/종료일 | 앱 열람일과 업체 규정 확인일은 다름 |
| 작성 주체 | 업체 게시, 플랫폼 정리, 방문객 후기, 알 수 없음 | 확인할 수 없으면 `작성 주체 미상` |

화면에 `반려동물 동반 가능`만 있고 세부 조건이 없으면 그 화면을 보내고 종료해도 된다. 상반된 안내를 발견하면 두 화면과 각각의 날짜를 모두 전달한다. 어느 쪽이 맞는지는 사용자가 고르지 않아도 된다.

## 6. 캡처와 전달 방법

### 최소 전달 묶음

장소당 아래 자료를 채팅에 첨부한다. 일반적으로 3~5장이면 시작할 수 있지만 분량이 길면 예외 조건이 잘리지 않도록 추가한다.

1. **장소명·주소 화면 1장**: 같은 지점인지 확인하기 위함.
2. **동반 안내 화면 1~2장**: 제목·조건·예외가 함께 보이게 한다. 내용이 없으면 `미기재`라고 알려준다.
3. **영업시간 상세 화면 1장**: 요일별 시간·휴게·휴무가 보이게 펼친다.
4. **공유 링크와 열람 날짜**: 앱의 공유 기능으로 링크를 복사한다. 복사가 안 되면 앱 이름과 검색어를 적는다.
5. 규정이 들어 있는 업체 공지가 있으면 **작성일·작성 주체·본문**이 보이는 화면을 추가한다.

사진·규정의 위치 관계를 알 수 있도록 확대 화면만 보내지 말고, 어느 가게의 어떤 안내인지 연결되는 화면도 포함한다. 관련 없는 계정 정보·예약 내역·위치·알림·리뷰 작성자 개인정보는 가려도 된다. 원문을 직접 타이핑할 필요는 없다.

### 채팅 전달 양식

아래를 복사하거나 같은 내용을 자유롭게 적는다. `미기재`, `검색 안 됨`, `접근 제한`, `주소 다름`도 그대로 적는다.

```text
[A01 누닝 펫푸드카페]
확인한 앱: 반려생활 / 네이버지도
열람일: YYYY-MM-DD (한국 시간)
공유 링크: ... (없으면 링크 복사 불가)
주소: 캡처에 포함 / 기존 주소와 다름
반려생활: 상세 있음 / 검색 안 됨 / 접근 제한 / 미조사
네이버지도: 상세 있음 / 검색 안 됨 / 접근 제한 / 미조사
찾은 자료: 동반 안내, 영업시간, 업체 공지 등
특이사항: 마릿수 미기재 / 앱마다 체중 다름 / 작성일 안 보임 등
첨부: 관련 화면
```

### code-server 폴더에 넣고 싶을 때

채팅 첨부가 편하면 폴더 작업은 생략한다. 파일로 전달할 경우 권장 위치는 아래와 같다. `.cache/`는 현재 Git에서 제외되며 **공개 저장소의 docs/·data/·public/에 캡처를 넣지 않는다.**

```text
.cache/incheon/user-research/YYYY-MM-DD/
  A01-nuning/
    banlife-01-place.png
    banlife-02-pet-policy.png
    naver-01-hours.png
    notes.md
  A02-gaette/
  A03-moonchina/
  A04-mudcoffee/
```

폴더·파일명은 예시다. 휴대폰 기본 파일명으로 보내도 되며, `notes.md`에 어떤 파일이 어느 앱인지 적으면 된다. 이 폴더는 자료 전달용 임시 공간이며 영구 데이터 저장소나 백업을 뜻하지 않는다. 제출한 캡처가 제품에 자동 공개되지는 않는다.

## 8. 대체 장소를 추가로 찾는 작업 — 선택

첫 조사에서 쓸 수 있는 정보가 확보된 생활권을 기준으로 진행한다. 처음부터 전국·인천 전체의 장소를 모으지 않는다.

- 문차이나를 중심으로는 `인천 차이나타운 반려견 동반 식당`을 검색해 **식사 가능한 곳 1곳**을 찾는다.
- 누닝을 중심으로는 `청라 반려견 실내 카페`를 검색해 **실내 휴식 가능한 곳 1곳**을 찾는다.
- 뻘다방을 중심으로는 `선재도 반려견 동반 카페`를 검색해 **같은 지역 카페 1곳**을 찾는다.

반려생활 → 네이버지도 순서로 보되, 첫 후보의 장소명·주소·공유 링크·동반 안내만 전달하면 된다. 안내가 명확한 후보가 없으면 `못 찾음`으로 종료한다. 이동시간과 KTO 연결 가능 여부는 Codex가 검토한다. **앱에서 발견한 장소가 PawProof 검색·대체 추천에 즉시 추가되는 것은 아니다.** KTO에 없는 후보는 별도 연결 설계와 출처 검수가 필요하다.

`같은 업종`뿐 아니라 실내 휴식·식사·야외 산책 등 원래 목적을 해결할 수 있어야 한다. 서로 먼 생활권의 장소를 대체 후보로 억지로 묶지 않는다.

## 9. 자료 수령 후 처리 기준

1. Codex가 장소·주소·지점을 대조한다. 다른 주소·지점은 보류한다.
2. 조건마다 근거와 적용 구역·기간을 연결한다. 자료에 없는 내용은 미확정으로 둔다.
3. 원천이 관광공사인 재게시 자료는 독립 확인으로 중복 계산하지 않는다.
4. 게시일·열람일·실제 업체 확인일을 구분한다. 후기의 방문 경험을 업체의 일반 규정으로 바꾸지 않는다.
5. 원출처·이용 조건을 검토해 서비스 반영 범위를 정한다. 플랫폼 화면을 볼 수 있다는 이유로 원문·캡처의 재게시 허용을 가정하지 않는다.
6. 반영 가능한 보완만 코드와 검증에 연결하고, 해결된 조건·남은 충돌·미기재 항목을 보고한다.

이번 조사 안내는 판정 엔진의 안전 기준을 완화하지 않는다. 모든 자료가 모여도 실데이터 대체 성공이나 실제 현장 입장 성공을 자동으로 완료 처리하지 않는다. 원문·파생 데이터의 저장은 [데이터 전략](DATA_STRATEGY.md)을 따른다.
