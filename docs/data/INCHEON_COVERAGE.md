자동 연결은 검수한 ID, 이름, 인천 주소, 도로명·건물번호를 모두 확인한다. 이름이나 번호가 바뀌면 적용을 중단하고 확인 필요를 남긴다. 주소 행정구역 명칭 변화와 지점 이동을 구분한다. 인천 차이나타운은 두 자료의 건물번호가 12와 20으로 달라 자동 병합하지 않았고, 인천대공원 놀이터는 238과 236으로 달라 보류했다. 같은 주소에 있는 강화성당과 원도심 코스도 같은 이용 범위라고 간주하지 않는다.

## 결합과 판정

1. KTO 원문을 실시간 조회하고 독립적으로 추출한다.
2. 검수된 인천시 행을 별도 출처로 추출한다. 모델 호출은 연결된 원문이 있는 장소당 1회 추가된다.
3. 규정 종류·실내외 적용 범위별로 비교한다. 한 출처에 없는 항목을 근거와 함께 보완한다.
4. 양쪽 규정의 연산·값·목록이 다르면 해당 구역의 규정을 unknown으로 남긴다. 더 엄격한 값이나 더 최근 게시일을 임의로 채택하지 않는다. 보수적인 비교이므로 표현상 차이도 추가 확인 대상이 될 수 있다.
5. 같은 출처 안에서도 동일 구역의 입장 허용·금지가 함께 있으면 확정하지 않는다. 다른 조건의 명확한 위반까지 지우지는 않는다.
6. 근거 화면에 출처별 원문, 수정·발행일, 조회·열람일, 가능한 연락처, 공식 링크를 표시한다. 업체 확인일은 확보하지 않았다고 표시한다.
7. 날짜가 명시된 공식 휴장은 별도 날짜 조건으로 적용한다. LLM의 규정 추출이 실패해도 확인한 공지 자체는 보존한다.

모델이 떨어진 필드의 문장을 합친 인용을 만들거나 연산자를 잘못 출력하는 사례를 발견했다. 스키마 전체가 유효한 경우 개별 규칙의 원문·의미 검증을 수행하고, 검증에 실패한 규칙만 제외한다. 하나라도 제외되면 확인 필요 사유가 남아 이용 가능으로 승격되지 않는다. 모든 규칙의 검증이 실패하거나 JSON 구조 자체가 잘못되면 추출 실패로 처리한다. 부분 보존을 의미 정확도 보장으로 표시하지 않는다.

## 갱신과 남은 확인

- 원본 CSV 발행일 2026-01-19와 2026-09-11 열람일을 구분한다. 발행일이 모든 업체의 실제 정책 확인일이라는 의미가 아니다.
- 다음 연간 등록 예정일인 2027-01-19 이후에는 재검수 전 자동 적용을 중단한다. 이는 운영상 재검수 기준이며 그 전까지 정책이 변하지 않는다는 보장이 아니다.
- 재검수 시 CSV 행 순서·내용 변경, KTO 이름·주소 변경, 임시 휴장 공지 종료·정정을 확인한다. 변경을 자동으로 덮어쓰지 않는다.
- 30곳 표본의 동반 마릿수는 모두 미확정이다. 공개 안내가 없는 조건을 ‘무제한’으로 넣지 않는다. [업체 확인 목록](INCHEON_CONFIRMATION_QUEUE.md)의 질문과 출처를 사용한다.
- 유효 대체 후보가 생겼다는 검증은 아직 없다. 자료 수·채움률과 최종 코스 이용 가능률을 분리한다.

## 재실행

```bash
python scripts/audit-incheon-source.py
node scripts/audit-incheon.ts --live
# 문제 장소만 재검사할 때
node scripts/audit-incheon.ts --live --ids=2603720,2848931,2767886
```

첫 명령은 공개 CSV의 행·채움률·해시와 선택한 9행의 변경 여부를 `.cache/incheon/municipal-source-audit.json`에 기록한다. 소스 변경 시 실패하며 제품 데이터를 자동 수정하지 않는다.

실 API 검사는 현재 키로 인천 목록을 조회한 뒤 보완 연결을 우선한 최대 30곳을 검사한다. 단일 장소 비교 조건은 골든리트리버 12kg·실외·2026-09-12 13시·30분이며, 실제 교통을 사용한 코스 검사가 아니다. 상한 KTO 110회·OpenRouter 42회, 자동 재시도 없음. CLI의 별도 실행마다 비용이 발생한다. 원문·추출 규칙은 파일에 남기지 않고 장소별 누락 종류·상태·출처 메타데이터·보고된 비용만 기록한다.

브라우저 스크립트는 `scripts/playwright/generated/pawproof-incheon-live-regional-search-supplement-4815923a51.js`다. 현재 로컬 미리보기에서 인천 검색, 3곳 검사, 휴장 판정, 출처·연락처·모바일 표시·입력만 저장을 검증하며 POST는 1회로 제한한다. 실제 호출 기록 방법은 [실 API 검증](../engineering/LIVE_VALIDATION.md)을 따른다.
