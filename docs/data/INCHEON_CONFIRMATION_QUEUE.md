## 먼저 확인할 질문

- 누닝 펫푸드카페·개떼놀이터·문차이나·뻘다방: 출처 간 체중·휴무·운영시간 차이를 먼저 확인한다. 현재 적용 조건, 예외, 실내외 범위, 시행일을 함께 질문한다.
- 모든 대상: 보호자 수와 무관한 일행 최대 반려견 수가 있는지, 보호자 1인당 제한인지, 예약·좌석에 따라 달라지는지 확인한다. 한 마리 방문 가능과 마릿수 무제한은 구분한다.
- 공원: 공원 산책·별도 반려견 놀이터·건물 내부의 규정을 구분한다. 체고 분리와 체중 제한을 혼동하지 않는다.
- 운영시간: 예정 체류 완료 시각까지 가능한지, 휴게·마지막 입장·임시 휴무·계절 운영을 확인한다.

확인 기록에는 장소 ID·주소, 확인한 담당 주체/경로, 확인 시각, 조건의 적용 공간·기간, 답변 근거와 재확인일을 남긴다. 개인 연락처나 통화 전문을 공개 저장소에 올리지 않는다. 사용자 개인의 통화 답변을 다른 사용자에게 공식 규정으로 자동 적용하지 않는다.
