# 인천 지역 검색과 업종 분류

2026-09-11 · 실제 KTO 응답으로 확인한 검색 계약.

기존 ‘인천’ 키워드 검색은 이름에 인천이 들어간 장소 5곳이었다. 현재 ‘인천’·‘인천광역시’를 입력하면 `areaBasedList2(lDongRegnCd=28)`로 지역을 조회한다. 지원 contentTypeId 12·14·28·39를 각각 최대 100행 조회하고 합계 최대 100곳을 반환한다. 동시 요청은 2개, 요청 수는 최대 4개다. 나머지 검색어는 이름 검색이다.

확인 결과는 **관광지 38곳·카페 4곳·식당 1곳, 합계 43곳**이다. 이는 현재 전용 API가 제공하는 지원 업종의 조회 결과이며 인천의 모든 실제 업소 수가 아니다. 과거 지역 코드 `areaCode=2`를 시험하면 15건만 반환됐으며, 상당수 현재 항목의 areacode는 비어 있었다. 현재 지역 검색에 과거 코드를 사용하지 않는다.

신규 업종 분류 `lclsSystm2=FD05`를 우선 사용한다. KTO의 `lclsSystmCode2(FD, FD05)` 응답에서 카페·찻집·기타음료점 하위 분류를 확인했다. 기존 cat3가 비어 있던 누닝·동양염전·뻘다방을 식당으로 잘못 분류하던 문제를 수정했다. 신규 값이 없는 경우에만 기존 cat3를 사용한다.

검증: 인천 실검색 43곳 반환, 공식 분류 조회에서 FD05 하위 카페 코드 확인. 합성 단위 검사에서 지역 파라미터와 신규 분류를 고정한다. 키·KTO 원문·장소 규정은 문서에 기록하지 않는다.
