# 제품 구현 실행 계획

2026-09-11 · 사용자가 기획·한국어 글꼴·디자인·구현 판단을 위임했다. 디자인 레퍼런스 ref/를 확인하고 루트 DESIGN.md를 구현 전에 작성했다. 키 안내는 작업 마지막에 제공한다.

## 순서와 기능별 커밋

1. 디자인 기준과 실행 범위 확정.
2. 규정 모델·순수 판정·일정 계산·대체 순위·입력 검증·가상 평가 데이터.
3. KTO·OpenRouter·카카오 이동시간 어댑터, 제한된 호출·서버 HTTP 계약과 실패 처리.
4. 한국어 랜딩·프로필·코스 편집·근거·대체·준비표의 인터랙티브 웹.
5. Playwright 전체 검증 자동화·모바일/프록시/운영 점검·문서 정합성과 설정 안내.

각 기능의 관련 검사 후 main에 작은 커밋을 남기고 승인된 푸시·Vercel 자동 배포를 진행한다. 초기 Firebase 미사용 범위에서 2026-09-13 계정 자동 저장·개인 검사 요약 복원까지 확장했다. 비회원은 메모리 전용 체험과 새로고침 경고를 제공하며 기기 저장은 제거했다. 상단의 제목·자동 저장 상태와 노트 목록으로 계정 여행을 관리한다. 공급자 규정 원문·인용문·추출 규칙은 저장하지 않으며 허용 필드·검증 범위는 [Firebase 기준](../engineering/FIREBASE_AUTH_AND_STORAGE.md)을 따른다.

## 데이터와 판정

최대 반려견 5마리, 당일 방문지 1~5개. 한 곳을 고른 뒤에도 코스 검사를 시작할 수 있다. 한국 날짜/시각과 분 단위 순수 일정 계산을 사용하며, 지원하지 않는 시간 표현·동물 규정은 미확인으로 보존한다.

규정은 구역별 제한·체중 상한과 포함 여부·마릿수·견종·준비물 AND/OR·운영 시간·휴무·근거로 구성. 개별 조건의 미확정과 명시적 제한 없음은 별도 표현. LLM 결과는 스키마와 원문 근거 존재를 검증한다. 문맥·의미 검증을 자동 근거 일치만으로 보장하지 않는다.

실제 모드: KTO 실시간 장소·원문 조회, OpenRouter 추출, 같은 규칙 엔진 사용. 가상 모드: 자체 작성 장소·규정과 표시된 가상 이동시간으로 전체 과업 체험. 키가 없어도 가상 기능은 작동하나 실제 서비스/API 연결 완료로 간주하지 않는다.

대체는 같은 유형·목적 후보 중 조건 충족·고정 방문 유지·이후 시간 충돌을 확인하여 비교. 미확인 후보는 적합으로 올리지 않는다. 조회한 후보 범위 내 비교이며 전역 최적화 보장 없음.

## 비용·호출

한 검증 최대 5곳, 규정 조회·추출은 제한된 동시 실행. 원문 길이·출력 토큰·HTTP 바디 크기·외부 응답 크기·타임아웃 제한. 자동 LLM 재시도 없음. 실사용 총비용은 OpenRouter 전용 키의 공급자 측 한도로 제한하며 인메모리 카운터를 전역 비용 보장으로 사용하지 않는다.

## 실검증 전 남는 조건

현재 키로 실 API 호출·모델 품질·권역 밀도·도로 시간·배포 안정성은 설정 후 검증 필요. 어댑터 fixture 테스트는 실제 공급자 연결 성공과 구분. 공식 제출 양식·실제 코스 평가 자료는 후속 제출 준비 항목이다.

## 현재 구현 결과

위 핵심 과업의 도메인·외부 어댑터·인터랙티브 화면과 테스트 자동화를 구현했다. 가상 체험 흐름은 전체 브라우저 검증을 수행했다. 실제 업체 정보로 확정된 코스·추출 품질과 공모전 제출 가능한 배포 상태는 아직 확보하지 않았다. [구현 기록](IMPLEMENTATION_STATUS.md)과 [API 설정](../engineering/API_INTEGRATION.md)을 따른다.
