## 30곳 품질 점검

현재 목록에서 보완 대상 9곳을 먼저 선택하고 목록 순서로 총 30곳을 점검했다. 무작위 표본·전국 품질 평가가 아니다. 골든리트리버 12kg, 실외, 2026-09-12 13:00, 체류 30분을 동일하게 대조했다. 개별 장소 검사에는 Kakao 이동시간을 사용하지 않았다.

초기 전부 거부 방식에서는 인용을 여러 필드에서 합친 규칙 하나 때문에 전체 규정이 실패하는 문제가 반복됐다. 인용 지침을 보완하고, 개별 규칙 검증 및 실패 항목의 확인 필요 처리를 추가했다. 마지막 23곳 재검사와 직전 검사에서 영향을 받지 않은 7곳을 합쳐 **고유 장소 30곳의 검사 메타데이터**를 확보했다. 서로 다른 실행을 합친 관측치이며 30곳 모두를 최종 코드로 동시에 재호출한 결과나 추출 정확도 100%를 뜻하지 않는다.

최근 비교에서 적용 구역의 규칙이 아예 없는 항목은 총 98개에서 96개로 감소했다. 누닝·뻘다방의 체중 규칙이 보완됐다. 다른 실행에서는 문차이나 체중·누닝 운영시간도 새 항목으로 집계됐으나 모델 추출 차이가 있으므로 최종 개선량으로 합산하지 않는다.

## 비용과 재현 자료

세 번의 CLI 점검 호출은 각각 KTO/OpenRouter 94/37, 94/35, 73/31회다. 두 번째 실행의 실패를 조사한 뒤 세 번째는 실패 대상과 보완 연결 대상 23곳만 재검사했다. API·LLM 요청 상한 안에서 실행했으며 자동 재시도는 없다.

세 CLI의 OpenRouter 응답 보고 비용 합계는 **$0.121607**이다. 별도 진단 3회의 보고 비용은 $0.0031519, 실제 브라우저의 6회는 $0.0068263이다. 합계 $0.1315852이며, 브라우저는 KTO 13회·OpenRouter 6회·Kakao 2회 모두 HTTP 200이었다. 청구서 검증이나 계정 전체 사용량이 아니다. 비용/원문/자격증명 경계는 [실 API 검사](../engineering/LIVE_VALIDATION.md)를 따른다.

로컬 메타데이터: `.cache/incheon/audit-*.json`, `municipal-source-audit.json`, `browser-*.json`. KTO 원문과 추출 규칙 전체는 파일에 남기지 않는다. 공공 이용이 허용된 인천시 CSV 분석 사본은 로컬 캐시에, 선택 9행은 제품 데이터에 저장한다. 변경 파일·분석 기록·운영 공개 정적 파일을 합친 81개 파일에서 설정된 인증키 일치 항목이 없었다.
