# 실제 API·브라우저 검증 기록

## 완료한 범위

| 항목 | 결과 |
|---|---|
| KTO | KorPetTourService2 검색·공통·반려동물·소개·위치 기반 조회 HTTP 200 |
| Kakao | 자동차 길찾기 HTTP 200, 실제 구간 소요시간 반환 |
| OpenRouter | google/gemini-2.5-flash 실제 추출 성공. 초기 스키마 거부 오류 수정 후 확인 |

| 사용자 화면 | 가상 모드로 대체하지 않고 live/kto/kakao 결과 표시, 브라우저 예외 0건 |

## 실호출에서 발견한 수정 사항

1. **모델 스키마 거부:** 길이·수치 제한이 중첩된 출력 스키마를 Gemini 제공자가 복잡도 초과로 HTTP 400 거부했다. 생성용 스키마의 범위/길이 제약만 단순화하고 서버 검증을 유지했다.
2. **조건 해석:** 표본의 연령 예외를 무시한 체중 제한, 제공 물품을 준비물로 해석한 결과, 지원하지 않는 휴무일 연산자를 발견했다. 종류별 연산자·KTO 필드 의미·지원하지 않는 예외 처리 지침을 보완했다. 확인한 표본에서 연령 예외는 unknown, 제공 물품은 준비물에서 제외, 연중무휴는 closedDays/all로 추출됐다. 전체 데이터 정확도를 보장하지 않는다.
3. **검색 누락:** 첫 20개에 섞인 쇼핑시설을 조회 후 제외하면서 뒤쪽 관광지가 누락됐다. 지원 contentTypeId를 요청 단계에 적용하고 동시 요청은 2개로 제한했다. 동일 ‘인천’ 검색의 표시 결과가 2곳에서 5곳으로 늘었다. 키워드 검색은 주소 전체의 지역 검색을 보장하지 않는다.
4. **실결과 화면 표시 실패:** 실데이터/실패 정책 객체의 `place`가 strict 클라이언트 정책 스키마와 충돌했다. 정책 생성 시 규칙과 출처 필드만 구성하도록 고쳤다. 합성 정상 결과만 확인하던 검사에 실 어댑터 정책 필드와 실패 응답 계약 검사를 보완했다.

## 실제 표본 코스

검증용 프로필: 골든리트리버 12kg → 20kg. 실제 반려견의 개인 정보가 아니다.

| 순서 | 장소 | KTO ID | 최초 결과 | 주요 미확인 항목 |
|---|---|---|---|---|
| 1 | 개떼놀이터 인천점 | 2848931 | 확인 필요 | 연령 예외, 마릿수·견종·준비사항, 자정 이후 운영/주문 마감 |
| 2 | 인천 차이나타운 | 264512 | 확인 필요 | 마릿수·견종·시간 관련 조건 |
| 3 | 자유공원(인천) | 125519 | 확인 필요 | 체중·마릿수·시간 관련 조건 |

최초 계산의 총 자동차 이동시간은 40분, 재검사 시 41분이었다. 현재 교통 기반의 조회 결과이며 미래 방문 시 소요시간 예측이나 보장값이 아니다. 20kg 변경 후 첫 장소의 체중은 연령 예외 때문에 확인 필요를 유지했다.

자유공원 대체 탐색에서는 **후보 2곳 검토, 유효 대체 0곳**이었다. 빈 후보 안내와 코스 보존을 검증했으며 **실데이터의 대체 적용·되돌리기 성공은 이번 표본에서 확인하지 못했다.** 해당 UI 흐름의 합성 데이터 회귀 검사와 구분한다.

성공한 브라우저 실행의 로컬 API 응답 시간:

| 동작 | HTTP | 관측 시간 |
|---|---|---|
| 장소 검색 | 200 | 649ms |
| 최초 코스 검사 | 200 | 5,872ms |
| 대체 탐색 | 200 | 11,987ms |
| 체중 변경 후 재검사 | 200 | 5,137ms |

각 1회 관측이다. 평균·백분위 지연이나 배포 성능으로 일반화하지 않는다.

## 호출·비용 기록

자동 메타데이터 기록에 포함된 연결 검사 5회와 브라우저 시도 2회의 합계:

| 공급자 | 요청 수 | 결과 |
|---|---:|---|
| KTO | 71 | HTTP 200 |
| Kakao | 14 | HTTP 200 |
| OpenRouter | 19 | HTTP 200 17회, 초기 스키마 오류 HTTP 400 2회 |

원문과 검색 누락 진단을 위해 이 밖에 KTO를 **13회** 추가 호출했다. 이번 작업의 KTO 합계는 **84회**다. OpenRouter의 HTTP 성공 중 2회는 수정 전 출력이 서버 의미 검증을 통과하지 못했다. HTTP 성공을 정책 검증 성공으로 집계하지 않는다.

응답 usage.cost로 합산한 OpenRouter 비용은 **$0.0167882**다. 실패 응답에 비용 항목이 없었으며, 이 수치는 최종 청구서 대조 결과나 계정 전체 사용량이 아니다. KTO/Kakao의 청구 금액은 측정하지 않았다.

변경 파일·로컬 검사 기록에서 인증키 일치 항목이 없었고, 운영 빌드의 공개 정적 파일 22개에서도 설정한 인증키가 검출되지 않았다. 키 값 자체는 검사 출력에 포함하지 않았다.

## 한계와 다음 과제

연결과 실제 사용자 흐름은 확인했지만 세 장소 모두 확인 필요였다. 명시적인 조건이 부족한 데이터에서 확정 판정·대체를 얼마나 제공할 수 있는지 추가 검수가 필요하다. 특히 마릿수, 연령 예외, 이용 공간, 복잡한 운영시간을 보완할 공식 정보 확보와 표본 확대가 다음 과제다. 이를 해결하기 위해 누락 조건을 ‘제한 없음’으로 처리하지 않는다.

LLM의 전체 의미 정확도, 실제 현장 입장, 유효 대체 적용, 전국 커버리지, 외부 Cloudflare Access/배포 서버/PWA 실기기/Firebase·인증은 이번 완료 범위에 포함하지 않는다. 재실행 방법은 [실 API 검증 안내](../engineering/LIVE_VALIDATION.md)에 있다.
